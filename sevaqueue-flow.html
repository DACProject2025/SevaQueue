Automated Scheduler

Three background jobs run automatically — no manual trigger needed
🕛

Expire Old Tokens — Midnight

Marks all WAITING/CALLED tokens from previous days as EXPIRED. Resets daily token count via a single bulk JPQL @Modifying UPDATE query.

0 0 0 * * *
Uses @Modifying + @Transactional on the repository query for efficient bulk update without loading all entities.
🔍

Mark Stale as MISSED — Hourly

CALLED tokens older than 1 hour → MISSED. WAITING tokens older than 2 hours → MISSED. Runs every hour from 8 AM to 8 PM.

0 0 8-20 * * *
🏯

End-of-Day Cleanup — 9 PM

At 9 PM, all remaining WAITING/CALLED tokens become MISSED. Office is considered closed for the day.

0 0 21 * * *
⚙ TokenScheduler.java — 3 Scheduled Methods
@Scheduled(cron = "0 0 0 * * *") // midnight

tokenRepo.updateExpiredTokens(); // JPQL bulk UPDATE
